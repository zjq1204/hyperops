# HyperOps 项目计划

## 目标
基于 devmind 架构，构建一个 DevOps 管理平台（代号 HyperOps），支持 Jenkins 任务触发和 GitLab 资源管理。

## 当前进度

### 已完成
- [x] 项目基础结构搭建（基于 devmind）
- [x] Jenkins Trigger 模块（后端 + 前端）
- [x] GitLab Resource 模块（后端 + 前端）
- [x] 用户认证系统（继承 devmind accounts）
- [x] 前端页面：登录、工作台、触发记录、管理配置
- [x] Docker Compose 开发环境配置

### 已修复的问题
- [x] `BigAutoAutoField` -> `BigAutoField` (Django 5+ 兼容)
- [x] 子模块手动克隆（agentcore-notifier, agentcore-task, agentcore-metering）
- [x] 添加 `python-gitlab` 依赖
- [x] 路由修复：`Login.vue` -> `Auth.vue`
- [x] 新增 `OAuthCallback.vue`
- [x] `fetchUser` -> `checkAuth` (router)
- [x] `landing_path` `/dashboard` -> `/home`
- [x] `UserDetailsSerializer` 添加 `auth_info` 到 fields 列表
- [x] PostgreSQL 配置启用
- [x] 初始迁移文件生成
- [x] API 单元测试脚本 (`test_api.sh`)
